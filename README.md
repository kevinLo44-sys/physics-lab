# Physics Lab Template

A clean, ready-to-use website template for university physics simulations.

## What's included

- **index.html** — Landing page with simulation cards
- **projectile.html** — Fully working interactive projectile motion simulation
- **styles.css** — Modern dark theme
- **projectile.js** — Simulation logic

## How to use

1. Open `index.html` in any modern browser (double-click the file).
2. Click **Projectile Motion** to try the simulation.
3. Move the sliders to change speed, angle, gravity, and air resistance.

## How to extend it

- Add new simulation pages (copy the structure of `projectile.html`).
- Update the cards on `index.html`.
- The physics calculation is in `projectile.js` — easy to adapt for other topics (collisions, SHM, etc.).
